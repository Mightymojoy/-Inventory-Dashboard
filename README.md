# ITO 库存看板 (Inventory Dashboard)

ITO 品牌电商库存日常管理看板。每日更新「库存-每日.xlsx」→ 一键刷新 → 双击打开成品看板。

## 文件说明

| 文件 | 说明 |
|------|------|
| `ITO库存看板.html` | **自包含成品**（数据内嵌，双击即开，无需服务器） |
| `build_inventory.py` | 构建脚本：读 Excel → 算指标 → 生成看板 |
| `inventory_dashboard.html` | 看板模板（不含数据，供构建脚本嵌入数据） |
| `inventory_data.json` | 最近一次构建的数据快照 |
| `刷新库存看板.bat` | 每日一键刷新脚本（双击即可） |

## 使用方式

1. 将每日 ERP 导出的库存表命名为 `库存-每日.xlsx` 放入本目录（数据源含业务数据，已通过 .gitignore 排除，不上传）
2. 双击 `刷新库存看板.bat`（自动探测 Python 环境并运行构建）
3. 构建完成后自动打开 `ITO库存看板.html`

手动刷新：
```
py build_inventory.py
```

## 看板模块

- 总览（KPI：在售 SKU / 可发库存 / 货值 / 缺货 / 预警 / 在途 / 到货）
- 库存健康度（缺货 / 急需关注 / 缺货风险 / 安全 / 滞销 五级分布）
- 缺货 & 预警清单（状态 + 分类筛选）
- 滞销清单（货值汇总 KPI）
- 到货监控（依赖「供应链提货计划表」，有则按日期日历、无则展示在途）
- 分类维度（品类 / 系列 / 状态 / 搜索 四重筛选）
- 商品 SKU 总览（全量正品目录）
- 旅行配件 & 赠品总览

## 口径说明

- 只看品牌为 ITO 的商品
- 货值按零售价计算
- 健康度阈值：周转 <7 天急需关注、<15 天缺货风险、>90 天滞销（可调整）

## 技术栈

- Python + openpyxl（构建）
- 纯 HTML/CSS/JS 单文件看板（金 #c9a962 + 白底极简，Lucide 风格图标）
